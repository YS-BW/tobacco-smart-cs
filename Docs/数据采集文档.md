## 2. 维基百科 PDF 采集

### 2.1 技术方案

维基百科提供 REST API 直接生成 PDF，无需浏览器渲染：

```
GET https://{语言}.wikipedia.org/api/rest_v1/page/pdf/{词条名}
```

对比两种方式：

| 方式 | 命令 | 耗时 |
|------|------|------|
| REST API | `curl -L -o xxx.pdf "https://zh.wikipedia.org/api/rest_v1/page/pdf/烟草"` | ~5秒 |
| Playwright | 打开浏览器 → 找按钮 → 点下载 → 保存 | ~15秒 |

REST API 更快、更通用、可批量调用。

### 2.2 采集过程

**第一步：搜索相关词条**

通过 Wikipedia API 搜索多个关键词，获取烟草相关词条列表：

```bash
curl -s "https://zh.wikipedia.org/w/api.php?action=query&list=search&srsearch=烟草&format=json&srlimit=50"
```

搜索关键词：`烟草`、`香烟`、`电子烟`、`控烟`，共获取约 50 个候选词条。

**第二步：筛选相关词条**

从候选列表中筛选与烟草行业客服相关的词条，去除无关条目（如"美国"、"清朝"、"黄仁勳"等）。

**第三步：批量下载**

编写 Shell 脚本，通过 REST API 逐个下载 PDF：

```bash
curl -L -o "维基百科_烟草.pdf" \
  "https://zh.wikipedia.org/api/rest_v1/page/pdf/%E7%83%9F%E8%8D%89"
```

注意事项：
- 需走代理（`http_proxy=http://127.0.0.1:7897`）
- 请求间加 3 秒间隔，避免触发 429 限速
- 文件名中括号等特殊字符需处理

## 4. 国家烟草专卖局政策文件采集

### 4.1 技术方案

国家烟草专卖局政策文件库（`http://www.tobacco.gov.cn/gjyc/zcwjk/zck.shtml`）是动态加载页面，内容通过 AJAX 接口获取。

**发现接口过程：**

1. Playwright 打开页面，确认内容是 JS 动态渲染
2. 查看页面源码，定位到 AJAX 调用代码
3. 找到接口地址和请求参数

**接口信息：**

```
POST http://www.tobacco.gov.cn/tobaccoweb/gjyc/search.htm
Content-Type: application/json

请求体：
{
  "tab": "zcwj",      // 政策文件标签
  "page": 1,          // 页码
  "sort": "dateDesc"  // 按日期降序
}

响应：
{
  "ok": true,
  "code": 200,
  "data": {
    "totalHits": 125,
    "resultList": [
      {
        "title": "文件标题",
        "url": "http://www.tobacco.gov.cn/gjyc/zhgl/202605/xxx.shtml",
        "docDate": "2026-05-27",
        "summary": "摘要..."
      }
    ]
  }
}
```

每页返回 10 条，共 13 页，总计 125 条政策文件。

### 4.2 采集过程

**第一步：获取全部文件链接**

通过 API 分页获取 125 条政策文件的标题、URL、日期：

```python
for page in range(1, 14):
    resp = requests.post(API, json={"tab": "zcwj", "page": page, "sort": "dateDesc"})
    # 解析 resultList，提取 title、url、docDate
```

**第二步：下载正文 HTML**

逐个访问文件 URL，保存完整 HTML 页面：

```python
resp = requests.get(doc['url'])
with open(f"{date}_{title}.html", 'w') as f:
    f.write(resp.text)
```

请求间加 0.5 秒间隔，全部 125 个文件下载成功。

### 4.3 HTML 结构分析

抽样 10 份文件分析 HTML 结构：

**正文容器：** `#NewsContentLabel`（125/125 文件 100% 命中）

**元数据：** 在 `<td>` 表格中，包含索引号、文号、发布日期、成文日期、公开责任部门。

**正文格式：** Word 粘贴风格
- `<p class="MsoNormal">` — 段落
- `<span style="font-family: 仿宋_GB2312; font-size: 16pt">` — 文字样式
- `<o:p></o:p>` — Word 残留标签
- `<font face="...">` — 旧式字体标签

**噪声来源：**
- 全站导航栏（`.inTop`、`.inNavs`）
- 底部栏（`.inBot`）
- 脚本/样式文件（每页 12 个）
- 表单元素（搜索框、按钮）
- 分享按钮（"分享到：微信分享"）
- 空 `<p>` 标签、空 `<span>` 标签

### 4.4 数据清洗

就地清洗原 HTML 文件，去除噪声，保留干净正文。

**清洗规则：**

1. **保留元数据表格** — 包含索引号、文号、发布日期等
2. **提取正文** — `#NewsContentLabel` 容器（取最内层）
3. **移除标签属性** — `tag.attrs = {}`，去掉所有 `style`、`class` 等
4. **移除 Word 残留** — `<o:p>` 标签
5. **移除空段落** — `<p>` 内无文本的直接删除
6. **解包样式标签** — `<font>`、`<span>` 解包（保留内容）
7. **移除空语义标签** — `<s>`、`<b>`、`<i>`、`<u>` 内无文本的删除
8. **组装输出** — `<!DOCTYPE html>` + 元数据表格 + 正文 `<p>`

**清洗效果：**

| 指标 | 清洗前 | 清洗后 |
|------|--------|--------|
| 总大小 | 5.5MB | 1.2MB |
| 压缩比 | - | -78% |

清洗后每个文件仅包含：
```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>文件标题</title></head>
<body>
  <table><!-- 元数据 --></table>
  <div id="NewsContentLabel">
    <p>正文段落1</p>
    <p>正文段落2</p>
    ...
  </div>
</body>
</html>
```

## 5. 国家烟草专卖局政策解读采集

### 5.1 技术方案

政策解读与政策文件共用同一个 AJAX 接口，区别在于 `tab` 参数：

```
POST http://www.tobacco.gov.cn/tobaccoweb/gjyc/search.htm

请求体：
{
  "tab": "zcjd",      // 政策解读标签
  "page": 1,
  "sort": "dateDesc"
}
```

接口返回结构与政策文件一致，共 158 条政策解读文章（2007-2026）。

### 5.2 采集过程

**第一步：获取全部文件链接**

分页获取 158 条政策解读的标题、URL、日期：

```python
for page in range(1, 17):  # 158 条，每页 10 条，共 16 页
    resp = requests.post(API, json={"tab": "zcjd", "page": page, "sort": "dateDesc"})
```

**第二步：下载正文 HTML**

逐个访问文件 URL，保存完整 HTML 页面，请求间加 0.5 秒间隔。

**第三步：过滤图解类文章**

政策解读中包含大量"图解"类文章（标题含"图解"），这类文章正文为图片而非文字，无法用于 RAG 检索。通过文件名关键词筛选并删除：

```python
# 删除标题含"图解"的文件（共 45 个）
for f in os.listdir(DIR):
    if '图解' in f:
        os.remove(f)
```

**第四步：删除空壳文件**

部分文件下载时未能获取到正文内容（页面通过 JS 动态渲染，`#NewsContentLabel` 为空）。逐个检查，删除无实质内容的空壳文件（共 51 个）：

```python
for f in os.listdir(DIR):
    soup = BeautifulSoup(open(f), 'html.parser')
    labels = soup.select('#NewsContentLabel')
    if not labels or not labels[0].get_text(strip=True):
        os.remove(f)
```

最终保留 50 个有实质内容的政策解读文章。

### 5.3 数据清洗

与政策文件使用相同的清洗规则：

1. 提取 `#NewsContentLabel` 正文容器（取文本最多的）
2. 移除所有标签属性
3. 移除 Word 残留标签 `<o:p>`
4. 移除空段落
5. 解包 `<font>`、`<span>` 样式标签
6. 移除空语义标签
7. 保留元数据表格，组装干净 HTML

**清洗效果：**

| 指标 | 清洗前 | 清洗后 |
|------|--------|--------|
| 总大小 | ~6MB | 1.5MB |
| 文件数 | 50 | 50 |

## 6. 国家行政法规库采集

### 6.1 技术方案

司法部行政法规库（`https://xzfg.moj.gov.cn/`）提供法规文件的 PDF 下载。

**定位过程：**

1. 通过 Playwright 打开 `https://xzfg.moj.gov.cn/search2.html` 搜索"烟草"
2. 找到《中华人民共和国烟草专卖法实施条例》条目
3. 进入详情页，发现页面提供 Word/PDF 下载按钮
4. 分析下载链接规律

**下载 URL 格式：**

```
https://xzfg.moj.gov.cn/law/download?LawID={法规ID}&type=pdf
```

烟草专卖法实施条例的 LawID 为 `1679`。

### 6.2 采集过程

直接通过 curl 下载 PDF：

```bash
curl -L -o "中华人民共和国烟草专卖法实施条例.pdf" \
  "https://xzfg.moj.gov.cn/law/download?LawID=1679&type=pdf"
```

文件大小 302KB，为司法部官方版本。
